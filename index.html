Three Lines. That's It.

Store a memory, read it back, done. No setup, no config, no SDK.

bash
# Store a memory
curl -X PUT https://membox.space-z.ai/api/m/YOUR-SLUG/user-preference   -H "Authorization: Bearer YOUR-TOKEN"   -H "Content-Type: application/json"   -d '{"content": "User prefers TypeScript and dark mode"}'

# Read it back
curl https://membox.space-z.ai/api/m/YOUR-SLUG/user-preference   -H "Authorization: Bearer YOUR-TOKEN"
